# Inkwell

A small Medium-style blogging platform built with Node.js, Express and MongoDB.

## Features
- Sign up, log in (JWT)
- Write, edit and delete posts, with drafts and markdown
- Tags, search and pagination
- Comments
- Rate limiting, validation and security headers

## Run locally
1. Install Node.js and MongoDB
2. `npm install`
3. Copy `.env.example` to `.env` and set your own `JWT_SECRET`
4. `npm run dev` and open http://localhost:5000
